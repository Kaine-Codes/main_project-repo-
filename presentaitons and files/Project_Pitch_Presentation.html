1. Introduction

Epilepsy affects approximately 50 million people worldwide, making it one of the most common neurological disorders. Current diagnosis relies on manual interpretation of Electroencephalography (EEG) signals by trained neurologists — a process that is slow, subjective, and unavailable in resource-limited settings.

Recent advances in Temporal Convolutional Networks (TCNs) have demonstrated that deep learning can classify EEG brain states with >97% accuracy. However, most solutions require cloud infrastructure — introducing latency, privacy risks, and connectivity dependencies that are unacceptable for real-time medical monitoring.

This project develops an edge-deployable AI platform that performs real-time EEG abnormality detection entirely on a local device, eliminating cloud dependency while preserving patient data privacy.

2. Objective

  • Design and implement an end-to-end pipeline for real-time EEG abnormality detection using deep learning on edge hardware
  • Interface the ADS1299 EEG ADC evaluation board for clinical-grade 24-bit, 256 Hz data acquisition across 5 EEG channels
  • Develop signal conditioning filters to produce a clean 5-electrode × 256-sample data matrix per second
  • Train and validate a TCN-based neural network for 4-state EEG classification (Interictal, Preictal, Ictal, Postictal)
  • Optimize and deploy the trained model onto an edge platform (Jetson Nano / Raspberry Pi 5) using TensorRT or TensorFlow Lite
  • Demonstrate real-time inference with <100ms latency and clinically viable accuracy (>95%)

3. Problem Statement

🏥 Clinical Gap

Manual EEG interpretation requires specialized neurologists and takes hours. Seizures can begin 20 minutes after preictal onset — early detection is critical but currently impractical at scale.

☁️ Cloud Dependency

Existing AI-based EEG solutions rely on cloud servers, introducing 200-500ms network latency, data privacy risks, and failure during connectivity loss — unacceptable for continuous medical monitoring.

⚡ Compute Constraints

Deep learning models (TCN, LSTM) are computationally expensive. Deploying them on low-power edge devices requires aggressive model optimization without sacrificing diagnostic accuracy.

📊 Signal Quality

Raw EEG signals contain significant noise — electrode artifacts, muscle movement, power line interference. The AI model requires clean, conditioned data to make reliable predictions.

The TCN architecture uses dilated causal convolutions with exponentially increasing dilation factors (1, 2, 4, 8, 16, 32) to capture both short-term spike patterns and long-term rhythmic changes — achieving >97% accuracy in published benchmarks while remaining parallelizable for edge hardware.

This project addresses a critical healthcare need — real-time, privacy-preserving epilepsy detection — by combining clinical EEG hardware with state-of-the-art edge AI.

Key Contributions
